# Copper Lung
Iron Lung recreation in Minecraft via [Minestom](https://minestom.net/) for the Nimcord 2025 GJ

If you're looking to play the game yourself, head to the [latest release](https://github.com/unsurprisable/copper-lung/releases/latest). It also has instructions.

[Game Trailer](https://youtu.be/YGUCpID1nMI?si=ZOH0nrDTCKbkKfio)

## Notice
This repository contains some art, audio, and concepts from Iron Lung by David Szymanski.
This was simply a passion project to faithfully recreate the game in Minecraft.
Please play the [Steam version of Iron Lung](https://store.steampowered.com/app/1846170/Iron_Lung/) if you haven't already to support the original developer.
